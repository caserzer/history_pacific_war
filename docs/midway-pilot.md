# 中途岛响应式样板

日期：2026-11-08。入口：`#/midway`。部署沿用仓库现有 GitHub Pages。

## 信息结构

- 正文：局势 → 地图与五阶段 → 约束和决策 → 结果与争议。
- 十四类分析均来自 `content/history.json` 的 `battle-midway.sections`，不复制历史正文。
- 参战者、指挥官、军力、作战计划、地理与完整经过放入具名补充阅读区；保持逐节证据入口。
- 引用：正文显示证据数量及类型提示；点击打开原生 modal dialog。桌面右侧抽屉，手机底部面板。完整来源独立于判断定位，并可筛选事实、解释和争议。关闭恢复触发元素焦点及阅读位置。
- 拓展：置于正文结束后，提供专题、探究问题、延伸阅读、完整来源。保留原版对照入口。
- 影像：消费 `content/media.json` 的中途岛历史照片及许可元数据。

## 地图设计与数据

新版地图独立于原 Atlas；全部阶段、舰位、航线、双方情报来自既有战役数据。地图默认显示太平洋地理背景，只标日本、中途岛、夏威夷；选择前四个阶段自动进入战区，第五阶段显示撤退的全局背景。战区标签来自阶段位置字段，明确区分中途岛守备与海上航母编队。

观察范围、缩放、复位、阶段、双方视角、不确定范围与说明均可使用按钮操作；桌面支持鼠标平移、方向键平移、加减号缩放及 0 复位。手机保留纵向页面滚动，不拦截地图区域的竖向触摸。无自动播放或位置过渡动画。

陆地数据：Natural Earth 1:110m land，自然地理背景，不表示 1942 年政治疆界。

- 来源：https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson
- 下载：https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_110m_land.geojson
- 许可：https://www.naturalearthdata.com/about/terms-of-use/ （公有领域）
- 本地资产：`src/features/midway/land.json`，28 个裁切多边形，约 10.5 KiB。
- 生成：`node scripts/prepare-midway-land.mjs <下载的 ne_110m_land.geojson>`。
- 处理：保留原始经度连续性，分别平移 0/360 度，裁切至东经展开 110–230 度、北纬 0–68 度，再保留三位小数。先裁切再展开，避免跨零度经线产生横穿太平洋的错误填充。
- 小岛使用既有地点坐标定位点；舰位及航线为示意，时间与位置不确定性均可查看。比例尺标明为纬向近似。

## 本地浏览器验证

在内置 Chromium 浏览器通过真实页面交互验证：

| 视口 | 结果 |
| --- | --- |
| 1280 × 720 | 封面双栏、固定侧边目录、阅读正文、右侧证据抽屉正常；默认文档高约 6,600px（原版约 35,800px）。 |
| 768 × 1024 | 目录与正文双栏；地图与阶段控制正常；无页面横向溢出。 |
| 390 × 844 | 单栏正文、可展开目录、底部证据面板；地图标签放大；无页面横向溢出。 |
| 320 × 740 | 最窄布局无页面横向溢出；战区地图、折行标题与按钮可用。 |

已验证：五个阶段逐一切换，日方/美方情报切换，太平洋/战区切换，展开不确定性说明，章节目录自动收起，证据关闭后焦点返回引用按钮，17/20px 阅读字号切换（手机无横向溢出）。DOM 确认十四类分析无重复、无缺失，默认不将证据全文铺在正文中。

本轮为交互样板验证，未声称 Safari/WebKit 实机、axe 审计或历史内容重新审核通过。用户将通过公开发布地址完成真实多设备验收，再决定是否推广。
