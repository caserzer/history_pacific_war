# 全站响应式阅读版

2026-11-08，将用户验收的中途岛样板阅读层次推广到整个教材。发布继续使用原 GitHub Pages 地址，既有 hash 深链保持有效。

## 当前生产结构

- `src/main.tsx` 加载共享历史内容并进入 `src/reading/ReadingSite.tsx`；所有生产路由都由同一应用渲染。
- `Reader.tsx` 为事件、战役、人物、专题、问题、装备和部队提供统一阅读版式。桌面侧栏目录，手机吸顶折叠目录；正文按完整句子增加阅读分段，历史原文字词不变。
- `Evidence.tsx` 使用单一全站证据面板。默认页面不展开证据全文；点击证据按钮才加载判断、类型筛选、定位与完整来源。桌面右侧抽屉、手机底部面板；原生 dialog 管理模态焦点，关闭恢复触发位置。
- `BattleMap.tsx` 覆盖珍珠港、珊瑚海、中途岛共 12 个阶段；战区范围从阶段坐标推导。支持全局/战区、缩放、鼠标/键盘平移、播放/暂停、双方情报、不确定范围、地点选择。触摸竖向滚动保留给页面；用户主动播放才会按 5 秒一步推进，不使用位置过渡动画。
- 手机主导航收纳为菜单；打开时锁定背景滚动并聚焦搜索框。正文和页脚在菜单展开时不可交互。
- 首次读者沿五个历史部分进入，事件和战役正文有下一篇；搜索同时覆盖地点、部队和装备，结果使用可读名称与正文摘要。
- 所有 22 项素材在对应文章中可查看，包括三张历史照片、五篇导读地图、五个人物图、六幅专题图解、三张可展开的静态作战图。来源页集中展示素材许可。
- 原 `#/midway` 地址作为中途岛章节别名；原六入口的详情链接、地图战役与阶段参数保留。无效实体 ID 显示可返回的未找到状态。

`src/features/*` 旧版视图保留为历史契约回归参照，不被当前生产入口调用；相关旧验证仍运行。新界面有独立验证，避免仅通过旧组件测试而遗漏实际线上页面。

## 内容层次

事件按正文小节阅读，早期扩张十类分析放在具名的深入分析区；三大战役十四类分析全部保留，补充背景与延伸阅读按需展开。人物先给出当时信息、实际选择、后果，再展开方案与约束。专题三层按顺序阅读。问题答案与相关线索分开。相关内容默认展示两条重点，其余放入“更多相关线索”。来源页判断分批显示，每批 12 条，可按类型过滤并打开单条证据定位。

## 地理底图与许可

采用 Natural Earth 1:50m land，作为现代自然地理背景，不表示历史疆界。阶段舰位与航线仍完全来自历史 JSON 并标为示意。

- 数据：https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_land.geojson
- 许可：https://www.naturalearthdata.com/about/terms-of-use/ （公有领域）
- 本地：`src/reading/land.json`，943 个多边形，约 263 KiB 原始 JSON。
- 再生成：`node scripts/prepare-reading-land.mjs <ne_50m_land.geojson>`。
- 算法：先按原始连续经度平移 0/360 度并裁切，范围为展开东经 60–300 度、纬度 -55–75 度；按 0.035 度容差简化折线，保留小多边形，坐标保留三位小数。比例尺为纬向近似；小岛也提供历史地点定位点。

地图完全本地绘制，不加载外部瓦片，不需要商业 Key。

## 验证

`node scripts/validate-reading.mjs` 构建并渲染真实生产应用，遍历 163 个页面状态：全部 93 个内容实体、7 个问题、31 个来源、12 个阶段深链，以及列表、搜索、无效 ID 与 fixture 标志；核对正文与分析保留、22 项素材显示、站内目的地、默认不展开证据。该检查加入 `npm run check`，因此 CI 与 Pages 构建都会执行。

本地内置 Chromium 实测 19 个代表性页面，在 320×844、390×844、768×1024、1280×844 四种视口下均无页面横向溢出。涵盖首页、全部主入口、三场战役、早期事件、人物、概念、问题、来源详情、装备及地点。

已验证交互：三场战役的全部阶段、双方视角、阶段 URL 同步、章节目录、手机菜单、人物阵营筛选、时间线部分筛选、证据类型筛选、完整来源、Escape 关闭与焦点返回。构建、既有站点契约与 full+media 内容门禁继续运行。

这些是浏览器视口与结构验证，不等同于 iOS Safari / Android / WebKit 实机或 axe 审计。历史叙述未在这轮重新审核；后续可根据真实多设备反馈继续调整排版与操作。
