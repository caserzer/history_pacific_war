# 扩展至日本正式签署投降书

## 范围

战争主线止于 **1945-09-02**，不是止于1945-08-15广播，也不延伸到战后审判、占领改革或各地随后举行的受降仪式。原有1931年起的战略背景和五个部分保留；新增五部分、22个事件（其中5篇导读）、5场重点战役、8位人物和24个地点。

| 部分 | 阅读主线 |
|---|---|
| 06 瓜岛与消耗战 | 巴布亚、科科达、瓜岛与长期海陆空补给 |
| 07 盟军反攻 | 俾斯麦海、绕过拉包尔、吉尔伯特与马绍尔、中国一号作战与缅印、马里亚纳及菲律宾海 |
| 08 重返菲律宾 | 莱特登陆、多路海战、指挥分工、吕宋和马尼拉平民灾难 |
| 09 逼近日本本土 | 硫磺岛、冲绳、地下防御、封锁、燃烧弹轰炸与平民经历 |
| 10 战争如何结束 | 波茨坦公告、原子弹、苏联参战、接受条件与广播、9月2日正式投降书 |

全站：41事件、8战役、22人物、70地点、13问题、53来源、486判断和55素材；27个战役观察阶段。五场新增战役各有完整十四类分析，每节至少160汉字。新增导读各有4个独立来源小节。人物先呈现背景、实际选择与后果，比较方案明确说明为分析框架，不冒充会议逐字记录。

## 来源与解释

新增22个文献登记，记录在 `content/history.json` 的 `source-late-*`。核心包括美国陆军及陆战队官方战史、USSBS调查与小泽/栗田受询记录、澳大利亚战争纪念馆、英国国家陆军博物馆、日本国立国会图书馆和美国国家档案馆。每个新增正文小节带来源与claim，事实、解释、争议和地图示意分开标注。

终章依据 [NARA投降书原件及说明](https://www.archives.gov/exhibits/featured-documents/japanese-surrender-document)、[NDL终战诏书登记](https://www.ndl.go.jp/constitution/e/shiryo/01/017shoshi.html) 和 [波茨坦公告原文](https://www.ndl.go.jp/constitution/e/etc/c06.html)。明确区分8月14日颁布/录音、15日广播、9月2日正式签字，区分重光葵、梅津美治郎、麦克阿瑟、尼米兹和各盟国代表的身份。原子弹与苏联参战的相对作用保留解释分歧，不以反事实伤亡预测充当已发生事实。

HyperWar的USSBS第10、12、14、16章HTML中存在建设中占位页；不将这些空页登记成已读取证据，改用可读的陆军/陆战队战史及受询原文。Navy站点在当前环境无法直连，图像仍通过可查阅的Commons档案登记核验。官方战史有军种与国家视角，战后受询有回忆和辩护局限；这些在各来源的可靠性说明中明列。未署年的现代博物馆网页以查阅年份登记并明确说明，不能据上传时间推断照片年代。

22位人物全部使用真实照片，新照片的身份、年代、原始URL、许可和实际文件尺寸记在 [portrait-sources.json](research/portrait-sources.json)。新增战役和受降影像记在 [late-war-photos.json](research/late-war-photos.json)。多数为公有领域；硫磺岛登陆车照片按来源的CC BY 2.0使用并保留USMC Archives署名。照片均本地托管；没有AI生成、上色或人物重绘。来源网站原有修复/裁切版本如实标明。

## 地图与阅读

地图从历史内容推导战役列表与阶段，从真实地点和部署范围推导观察区域。时间戳用于按日阶段排序，不代表记录了精确到午夜的行动；同日并行行动的切片不假装依次发生。部队坐标、方向线和不确定范围均明确为教学示意，而非重建的舰船或步兵航迹。

保留Natural Earth 1:50m全局底图，并为瓜岛、硫磺岛和冲绳提取1:10m局部海岸线。数据为现代自然地理，不代表1945年疆界或岸线测量成果。尤其硫磺岛火山岛后来发生地形变化，图中海岸线只能提供现代地理参照。

- 数据：[Natural Earth 1:10m land](https://www.naturalearthdata.com/downloads/10m-physical-vectors/10m-land/)，[GeoJSON上游](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_10m_land.geojson)。
- 许可：[公有领域](https://www.naturalearthdata.com/about/terms-of-use/)。
- 本地：`src/reading/local-land.json`，28个多边形，约29KiB；全局仍使用`land.json`。
- 再生成：`node scripts/prepare-late-war-land.mjs <ne_10m_land.geojson>`；局部多边形使用五位小数，仅改变数值精度，不扩展为历史地图精度声明。

比例尺随当前范围和缩放计算，不再在小岛战区固定显示100公里。战役选择器支持8场；与所选战役无关的地点只展示地理定位，不显示珍珠港等早期战役的情报。文章前默认最多展示一项主影像，其余图解在可展开补充区，避免两张大图连续挤占正文。

## 契约与验证

schema、TypeScript历史部分枚举、标签与coverage同时扩展至十部分，日期上限为1945-09-02。重点集合由19扩为29，类型要求由22槽扩为37槽，原重点文章深度不降低。新增17个非导读事件作为requiredEvents登记，使未来缺失会触发门禁。媒体可关联已登记必需事件，未知ID仍拒绝。

验证包括`npm run check`、`npm run build`、`--stage full --media`、`--self-test`与`--check-contracts`。阅读验证遍历全部实体、问题、来源、27个阶段与内部链接，并验证十部分入口、终章日期和代表、终章无下一篇、受降地点不出现无关战役情报，以及各战区比例尺没有超出画布。旧地图回归仍保留原三场战役的12阶段检查，选择器和时间线检查则覆盖扩展后的全部真实数据。

人工通过联系表检查新增14张照片，在390px移动视口验证小岛海岸线、阶段切换、盟军视角与阶段URL同步；桌面和移动验证属于浏览器视口检查，不冒充iOS或Android实机验收。
