# 历史内容适龄与证据评审 Rubric（v1）

适用对象：11 岁左右的中文读者；也用于编辑、内容创作者和测试者的共同评审。

本 rubric 是**人工评审标准**。`scripts/validate-content.mjs` 能检查结构、覆盖、引用和最低篇幅，但不能证明文章适龄、通顺、准确或有同理心。可读性评审必须由内容负责人/测试者在 `tests/evidence/pedagogy.md` 中提交记录；在该文件提交前，不得宣称“可读性通过”。

## 0. 一页判定

一篇重点文章只有同时满足以下条件才可进入内容验收：

- [ ] 一个 11 岁读者能在不查额外资料的情况下，说出“发生了什么、为什么会这样、还有哪些解释”。
- [ ] 没有为了戏剧性编造对话、内心活动、精确位置或数字。
- [ ] 关键日期、数量和判断都能通过 `claim.locators` 追溯到具体来源位置。
- [ ] 事实、解释、争议、示意四类信息在正文/UI 中有明确区分。
- [ ] 写侵略、平民苦难和战争罪行时清楚、克制、不血腥，不把集体污名化。
- [ ] 不把失败归因于“某人失误”或“运气不好”而不解释当时的条件、选项和约束。
- [ ] 结尾有少量高质量探究问题，答案有证据关联，不以背诵数字为主。
- [ ] 术语按“是什么 → 怎么运作 → 为什么影响决策”分层解释。

## 1. 读者与语气

### 1.1 可读性目标

- 默认读者：11 岁、具备基础世界历史常识，但不知道“航母战斗群”“情报截获”“战列舰”等术语。
- 语气：清楚、尊重、有叙事张力，但不幼稚、不说教、不把战争写成游戏或英雄漫画。
- 避免“小朋友们，让我们……”这类幼儿化开场；也避免连续堆叠专业名词。
- 中文句子以短句为主。一个句子表达一个主要意思；超过约 35 个汉字的复合句应考虑拆分。
- 第一处出现的外国地名/舰名/机构名给中文译名，必要时附原文；之后保持一致。
- 用具体比较帮助理解数量级，例如“这大约相当于……”；但比较本身也要可核查，不能编造。

### 1.2 分层术语卡

每个核心概念至少有三层，且三层是**递进**而不是重复：

1. **是什么**：用日常语言给定义，说明它解决什么问题。
2. **怎样运作**：按步骤解释人员、设备、时间和限制。
3. **为什么影响历史**：放回具体战役/决策，说明它改变了哪些选择或风险。

示例（航母，不是成稿）：

- 第 1 层：航母是能让飞机从海上起飞和降落的军舰，相当于移动的机场。
- 第 2 层：飞机起飞、返航、加油、装弹和甲板调度需要时间；航母必须迎风航行，舰队还要防空和反潜。
- 第 3 层：中途岛时，谁先发现对方、谁先完成攻击准备，会影响整场战斗的时间差；所以“多一艘航母”不等于“自动获胜”。

不合格：用“航母就是海上霸主”代替机制解释；用拟人化“航母发怒”代替作战流程。

## 2. 叙事结构：因果而不是结论

推荐结构：

**局势 → 问题 → 可选方案 → 实际决策 → 双方行动 → 意外变化 → 结果 → 长期影响**

### 2.1 每个重要决策必须回答

- 当时知道什么？不知道什么？信息来源可靠吗？
- 决策者面对哪些硬约束：燃油、弹药、航程、天气、通信、时间、指挥链、政治压力？
- 至少两个现实备选方案是什么？为什么没有被选？
- 选择后出现了哪些计划外变化？
- 哪些结果在当时可预见，哪些只有事后才知道？

### 2.2 禁止的归因方式

- 禁止无证据的“因为指挥失误所以失败”。
- 禁止用最终结果反推“当时显然应该……”；必须说明当时可见的信息。
- 禁止把复杂结果归因于单一因素（“全靠运气”“全靠密码破译”）。
- 禁止把人物写成无缺点的英雄或无动机的反派。可以评价行为，但要给出证据与语境。
- 区分“必要原因”“充分原因”“加速因素”“偶然因素”；不要把它们混为一谈。

## 3. 证据类型与 UI 展示

正文和界面必须让读者看见证据类型，而不只是在小字里塞链接。建议的四种展示标签：

| 类型 | 中文显示 | 含义 | 正文/UI 要求 |
|---|---|---|---|
| documented fact | 事实 | 有同时代文件、官方记录或可靠研究直接支持 | 显示来源机构与具体定位；数字写口径 |
| interpretation | 解释 | 对事实之间关系的学术解释，通常有竞争解释 | 明确“历史学者认为/一种解释是”，不冒充事实 |
| disputed | 争议 | 来源或学界存在实质分歧 | 并列主要说法、证据强弱与仍未解决的问题 |
| teaching simplification | 教学简化/示意 | 为理解而做的地图、时间或比喻简化 | 就地标注“示意”，说明简化了什么 |

### 3.1 引用与定位

- 每一处日期、舰艇/飞机数量、伤亡数字、人物判断和因果判断，都应关联 claim；claim 必须有非泛化的 locator。
- 网页来源使用“小节标题 + 段序”；书籍/PDF 使用页码或章节；档案使用馆藏号/条目号；口述史使用转写行号或时间码。
- 不把来源首页当作定位；不把搜索摘要当作证据。
- 数字出现冲突时，正文说明“采用哪一口径、为什么”，并用 `disputed` claim 记录其他说法。
- 引用原文时才使用引号；不得编造或“润色”历史人物的话。

### 3.2 事实、解释、争议的写作示例

不合格：

> 南云因为犹豫不决，错过了最佳时机，导致日本输掉中途岛。

问题：把复杂决策压成性格判断；没有说明他当时收到什么情报、航母甲板在做什么、换弹命令的具体约束。

合格方向（示例，需由实际来源支持）：

> 6 月 4 日上午，南云面对相互冲突的情报：侦察机报告发现美国舰艇，但尚未确认是否有航母；同时，第一波攻击机返航需要回收、加油和重新装弹。不同研究对“换弹命令”的时间和影响仍有争论。把这一段写成“他犹豫了”会掩盖真正的问题：在信息不完整、时间紧迫和甲板调度受限的条件下，任何选择都要付出代价。

## 4. 年龄适宜性：侵略、平民苦难与战争罪行

### 4.1 必须做到

- 明确说明日本在 1930—1940 年代对中国及亚洲多地的侵略战争，不把太平洋战争写成从珍珠港突然开始的“美日海战”。
- 明确写出侵略行为、殖民统治、强制劳动、战俘虐待、平民屠杀等基本事实，但使用非血腥、非猎奇的语言。
- 让受害者有尊严：不描述尸体细节、不渲染性暴力、不用受害者的痛苦制造“刺激感”。
- 区分日本帝国政府/军部/具体部队与普通日本民众；不进行民族整体污名化。
- 说明盟军也有战争罪行或政策错误（如对平民造成伤害的行动、拘禁日裔美国人等），但不要把“双方都有错”当作抵消侵略责任的借口。
- 允许写出“不知道”“有争议”“资料不足”；这比编造细节更适龄。

### 4.2 语言尺度

可以使用：

- “日军占领了……”“大量平民被杀害”“幸存者被迫……”
- “这是一场侵略战争”“战俘受到虐待，很多人死亡”
- “具体死亡人数仍有不同统计，本文采用……”

避免：

- 逐帧描写斩首、肢解、性暴力、尸体堆积、酷刑细节。
- 用“野兽”“恶魔”“蛆虫”等非人化称呼。
- 用“游戏般的胜负”“我们赢了”替代对平民代价的说明。
- 把战争罪行写成“个别士兵失控”而不说明指挥、政策与制度背景。
- 把侵略说成“进入”“事件”或“冲突”以淡化责任。

### 4.3 议题最低覆盖

背景/扩张文章至少交代：

- 日本对中国的侵略与资源需求；
- 美国禁运与双方战略困境；
- 东南亚殖民体系与资源争夺；
- 平民在占领下的处境，选择一个有来源的具体例子，不做猎奇描写。

战役文章至少交代：

- 战斗对当地居民、战俘或环境的影响（有可靠来源时）；
- 不以舰艇损失数字替代人的代价；
- 对战争罪行的判断须有来源，不能靠情绪化形容词。

## 5. 地图与不确定性

- 地理节点（places）是真实已知地点，必须同时有历史名与现代名；不要把估计舰队位置写成地理节点。
- 舰队/飞机航线一律标为示意；说明这是“根据来源重建的示意，不是精确航迹”。
- 阶段位置必须有不确定半径/说明；不能为了好看画出精确到米的线。
- 同一阶段展示双方视角时，必须分别写清已知与未知敌情，不用全知视角替代当事人视角。
- 地图上的“胜负”色彩不应暗示道德判断；用图例说明阵营、时间、方向和不确定性。

## 6. 问题与答案

每个历史部分至少一个实质性探究问题。合格问题：

- 问因果、比较、证据或决策，而不是只问年份。
- 有 160 个汉字以上的回答（由覆盖门禁强制），包含至少两个内容实体、来源和 claim。
- 回答承认不确定性：哪些是事实、哪些是解释、哪些仍有争议。
- 不把假设情境写成真实历史；如做决策模拟，明确标注“假设”。

不合格问题：

- “珍珠港是哪一年发生的？”（机械记忆，缺少探究）
- “日本为什么那么坏？”（道德标签，缺少历史解释）
- 问题有答案但答案只有关键词或口号。

## 7. 人工评审流程与证据

`tests/evidence/pedagogy.md` 至少应记录：

1. 评审日期、评审人、文章 ID、内容版本/提交。
2. 目标读者抽读方式（例如请一名 11 岁读者朗读/复述）。
3. 每篇文章的“读者能复述的因果链”记录。
4. 术语分层检查：三个核心概念是否做到“是什么—怎么运作—为什么影响决策”。
5. 证据类型检查：随机抽取至少 5 个日期/数字/判断，核对 claim 和 locator。
6. 敏感内容检查：侵略、平民苦难、战争罪行的表述是否清楚、非血腥、无集体污名化。
7. 问题质量：五个历史部分各至少一个；答案是否真正解释而不是复述。
8. 未通过项、修改记录与复审结论。

结构验证器通过 + `--media` 通过 + 人工 rubric 通过 + 浏览器/无障碍检查通过，才可称为内容可交付。任何一项缺失都应在交付说明中明确列为未完成。

## 8. 评审严重度

- **阻断（必须修复）**：编造事实/引文/数字；无来源的关键数字；把侵略合理化；血腥猎奇；集体污名化；事实/解释/争议混淆且会误导；地图精确航迹造假。
- **重要（应修复）**：因果链缺失；决策只写结果不写约束；术语未分层；问题只有记忆题；引用定位过泛。
- **建议（可改进）**：句子过长；重复；标题不清晰；缺少过渡；视觉素材与正文关联弱。

## 9. 快速检查清单

- [ ] 标题不是“战役名称 + 日期”的空壳。
- [ ] 开头交代局势和问题，而不是直接进入战斗。
- [ ] 至少两个决策点写出选项、约束、信息与后果。
- [ ] 日期、数量、判断都能定位。
- [ ] 事实/解释/争议/示意在正文可见。
- [ ] 有平民、战俘或占领地人民的处境，且不猎奇。
- [ ] 没有编造对话、引文、舰队精确位置。
- [ ] 地图阶段标注“示意/不确定”。
- [ ] 问题能引发比较、因果或证据分析。
- [ ] 读者能说出“为什么”，而不只是“谁赢了”。
